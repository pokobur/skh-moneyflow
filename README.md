# SKH マネーフロー & 資産管理 Webアプリケーション

Excelワークブック（`SKH2026.xlsx`）による年次単位の個人マネーフローおよび資産管理を完全再現・拡張したWebアプリケーションです。

---

## 🌟 主な機能と特徴

1. **年次・月次グリッド入力（ExcelライクUI）**
   - 1月〜12月を横軸に並べたスプレッドシート型インライン入力。
   - `Enter` で下の行へ、`Tab` で右のセルへスムーズにフォーカス移動。
   - フォーカス時は数値のみ、ブラー時にカンマ整形。

2. **分離された収支計算ロジック（Excel数式の完全再現）**
   - **純支出**: 生活費、家賃、カード、光熱費、Amazon等の実費消費のみを集計。
   - **投資・積立枠（資産移動）**: WealthNavi、FX、仮想通貨、GMO株、積立は「純支出」から分離し、資産形成枠として管理。
   - **総合収入**: 仕事収入（給与・副業）＋ 支援物資（固定・臨時）。
   - **月次差額**: 総合収入 － 純支出。

3. **残高推移と先月比（MoM）の自動集計**
   - **銀行預金・証券**: 毎月29日時点のスナップショット。
   - **電子マネー**: 月末時点のスナップショット。
   - 証券先月比、銀行先月比、総資産先月比をリアルタイム算出（±色分け表示）。
   - 休止口座（GMO FX、SBIトレード等）の非表示/表示切り替え対応。

4. **金融機関用途・引落情報の一体管理**
   - 各費目の引落日・引落口座をインライン管理＆サジェスト選択。
   - 金融機関ごとの用途・運用メモ（例:「じぶん銀行: メインバンク＋外貨積立」「ソニー銀行: 送金＋投資用」等）をインライン編集可能。

5. **ビジュアルダッシュボード（Recharts）**
   - 年間純差額、現在総資産、総合収入、純支出、投資積立枠のKPIカード。
   - 総合収入 vs 純支出 vs 月次差額のコンポジットチャート（棒＋折れ線）。
   - 銀行預金＋証券投資の総資産推移スタックエリアチャート。
   - 支出費目別シェア＆最新ポートフォリオ構成比ドーナツチャート。

6. **年度繰越機能（新年度作成）**
   - 前年度の費目構成・引落設定を引き継ぎ、口座残高の最新月を新年度1月の初期残高へ自動セット。

7. **Excel互換入出力（SheetJS）**
   - `SKH2026.xlsx` と同一の5シート構造（支援、収入、支出、資産、電子）で `.xlsx` エクスポート。
   - 既存Excelファイルのインポートによるデータ復元。
   - LocalStorageによる自動保存（オートセーブインジケーター付き）。

---

## 🚀 起動方法

```bash
cd skh-money-manager
npm run dev
```

ブラウザで `http://localhost:3000` を開いてご利用いただけます。

---

## 🛠 技術スタック
- **Frontend Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Lucide Icons
- **Chart**: Recharts
- **Data Persistence**: LocalStorage (ローカルファースト、即時動作)
- **Excel I/O**: SheetJS (`xlsx`)
